# ReportFlow
Приложение для автоматической генерации красивых PDF отчетов из CSV файлов.

## ✅ Что будет реализовано:
1. **Полная структура проекта** с разделением на два микросервиса
2. **Валидация входных данных** (проверка расширения файла, существования путей)
3. **Обработка ошибок** с логированием на всех уровнях
4. **Callback механизм** - Python API уведомляет .NET API о завершении обработки
5. **Асинхронная обработка** задач в Python (не блокирует запрос)
6. **Красивая генерация PDF** с использованием ReportLab (стили, цвета, форматирование)
7. **Docker Compose** для легкого развертывания всей инфраструктуры
8. **Документация** с примерами использования
9. **Тестовые данные** для проверки работы системы

## 🏗️ Архитектура
Проект состоит из двух микросервисов:
1. **Client API (.NET 8)** - принимает файлы от пользователей, управляет задачами
2. **Python API (FastAPI)** - обрабатывает CSV файлы и генерирует PDF отчеты
